# Rig Safety Guardian

Build "RigMind", a rig safety-operations web app (React + TypeScript + Tailwind + shadcn/ui), front-end only with mock data. No backend, no auth, no real video. Use React Router with one route per screen, and keep all data in a single typed mock-data module (src/data/mock.ts) so it can be swapped for real APIs later.

## Visual style (light theme, enterprise, calm)
- Font: IBM Plex Sans for UI; IBM Plex Mono for IDs, timestamps, rule IDs, signal names.
- Colors: page bg #F1F4F7, cards #FFFFFF with 1px border #DCE2E9 and 8px radius, inputs bg #F5F7FA, text #172131, secondary text #4A5566, primary #2361B5 (hover #1B4F96), active nav bg #E8F0FB.
- Status chips (small, 4px radius, 10px text, tinted bg + border): Critical #B4351E on #FDF1EE; Warning #8A5300 on #FFF8EC; Advisory #2559A8 on #F0F5FD; Success/Ready/Online #1D6E45 on #F0F8F3; Neutral #2B3544 on #F1F4F7.
- Charts: critical #B4351E, warning #D9A35A, advisory #8AADE0. Avatars: dark slate #3B4350 circles with white initials.
- Page header pattern: small uppercase tracked eyebrow (e.g. "OPERATIONS / OVERVIEW"), 28px semibold H1, one-line subtitle, actions right-aligned (secondary outline buttons + one primary blue button).
- Info callouts: light grey box with a 3px blue left accent, bold title + one-line text.
- Use lucide icons. Make all layouts responsive (sidebar collapses on mobile; wide tables scroll horizontally).
