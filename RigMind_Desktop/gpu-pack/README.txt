RigMind GPU runtime (NVIDIA): TensorRT 8.6, CUDA 11.8 runtime libraries, cuDNN 8.9 (inference).
Needs an NVIDIA GPU (Turing or newer) and a current NVIDIA driver. Without it RigMind falls back to CPU, which is slow.
1. Install RigMind (RigMind-1.0.0-win64.exe).  2. Unzip this file.  3. Run install-gpu.cmd as administrator.
These libraries are NVIDIA's; their licence terms apply (CUDA Toolkit, cuDNN and TensorRT licence attachments).
